# 📈 Stock Market Analyzer

A modern, responsive web application for real-time stock market analysis, visualization, and portfolio monitoring. Built as an MCA project.

---

## 🚀 Features

- **Live Market Dashboard**: Real-time stock status indicator and key market indices tracking.
- **Interactive Financial Charts**: Powered by [Chart.js](https://www.chartjs.org/) for dynamic price history, trends, and analytical insights.
- **Market Flow**: Visual flow of sector performances and top gainers/losers.
- **Watchlist & Portfolio Tracking**: Add, remove, and track favorite stocks seamlessly.
- **Modern UI / UX**: Cyberpunk/fintech dark aesthetic featuring glow effects, responsive grid, and smooth navigation.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Data Visualization**: Chart.js
- **Styling**: Modern CSS Grid & Flexbox with custom glow effects and glassmorphism
