ABOUT PROJECT

Stock Market Analyzer

Stock Market Analyzer is a frontend web application developed as an MCA academic project. The application fetches financial information from the Alphavantage API and presents it through an interactive dashboard.

Users can search stocks, view market statistics, analyze historical prices, visualize trends and maintain a personal watchlist.
